# Security policy

## Supported versions

Only the latest released version of `@seungyeop-lee/beads-desk` receives security fixes. Before reporting, check whether the problem still occurs on the latest version.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Report it privately through GitHub private vulnerability reporting:

1. Open the repository's [security page](https://github.com/seungyeop-lee/beads-desk/security) and click **Report a vulnerability**.
2. Describe the vulnerability, the affected version, the steps to reproduce it, and its impact.
3. Click **Submit report**.

The maintainer is notified, and you are added as a collaborator on the proposed advisory.
